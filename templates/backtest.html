📊 Walk-Forward Backtest Evaluation

Evaluate how the advisor's recommendations would have performed on historical data

How It Works

  1. Historical stock data is split into rolling train/test windows
  2. A model is trained on each training window (no future data leakage)
  3. Signals (Buy/Hold/Avoid) are generated on the test window
  4. Portfolio performance is simulated following those signals
  5. Results are compared against a buy-and-hold benchmark
